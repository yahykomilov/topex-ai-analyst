# Topex AI Analyst — бот аудита звонков (AmoCRM → Telegram)

Бот: **@Topex_AI_Analyst_bot**

## Что делает

- 🤖 **Авторежим (AmoCRM подключён):** сам находит новые звонки в AmoCRM, скачивает запись, расшифровывает, делает жёсткий аудит по промпту РОПа и присылает в Telegram аудио + отчёт + ссылку на карточку сделки.
- 👥 **Меню по сотрудникам:** /start или /menu → «Сотрудники» → выбираете менеджера → видите его статистику (% успешных ✅ / неуспешных ❌ / под вопросом ❓, средний балл) и список его звонков → открываете звонок → диалог по ролям + полный разбор AI.
- 🔍 **Разбор старых звонков:** в карточке сотрудника кнопка «Разобрать последние звонки из CRM» — анализирует по 3 звонка за нажатие.
- 📊 **Общая статистика отдела** — сводка по всем менеджерам.
- 🎧 **Ручной режим (работает всегда):** пришлите боту запись звонка (mp3/wav/ogg/голосовое) или текст расшифровки (сообщением или .txt) — получите отчёт. Такие звонки попадают в раздел «📤 Ручные загрузки».

## Запуск

1. Дважды кликните **start.bat** (или в консоли: `python main.py`).
2. В Telegram откройте @Topex_AI_Analyst_bot и отправьте **/start** — этот чат станет владельцем, все отчёты будут приходить сюда.
3. Проверка: пришлите боту любую запись звонка.

Бот работает, пока запущено окно start.bat и включён компьютер.

## Подключение AmoCRM (когда будет токен)

1. В AmoCRM: Настройки → Интеграции → Создать интеграцию → Внешняя интеграция → «Сгенерировать долгосрочный токен».
2. Откройте файл `.env` и заполните:
   - `AMO_SUBDOMAIN=вашподдомен` (из адреса вашподдомен.amocrm.ru)
   - `AMO_ACCESS_TOKEN=токен`
3. Перезапустите бота (закройте окно и снова откройте start.bat).
4. Команда **/status** в боте покажет, что AmoCRM подключён.

При первом запуске с AmoCRM старые звонки пропускаются — бот следит только за новыми.

## Настройки (.env)

| Параметр | Значение |
|---|---|
| `MIN_CALL_DURATION` | Минимальная длительность звонка в секундах (короче — пропуск). По умолчанию 20 |
| `POLL_INTERVAL` | Как часто проверять AmoCRM, сек. По умолчанию 120 |
| `ANALYSIS_MODEL` | Модель анализа OpenAI. По умолчанию gpt-4o-mini (дёшево). Можно gpt-4o (качественнее) |
| `ANTHROPIC_API_KEY` | Если заполнить — анализ пойдёт через Claude (ещё качественнее) |

## Стоимость

Сейчас всё работает через **Groq (бесплатный тариф)**: и расшифровка (whisper-large-v3-turbo), и анализ (llama-3.3-70b). На бесплатном тарифе есть лимиты по количеству запросов в минуту/день — при большом потоке звонков возможны паузы.

Платные варианты (качественнее/стабильнее), включаются в `.env`:
- OpenAI (пополнить баланс): расшифровка + анализ ≈ 3–4 руб за 5-минутный звонок
- Claude (ANTHROPIC_API_KEY): самый качественный анализ

## Сброс владельца бота

Удалите файл `data/state.json` и перезапустите бота — первый, кто отправит /start, станет новым владельцем.

## Если что-то не работает

- Запустите `python main.py` в консоли и посмотрите текст ошибки.
- Команда `/status` в боте показывает состояние подключений.
